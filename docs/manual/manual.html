Pixels Dice Hub

User manual
ESP32-S3 1.64″ AMOLED touchscreen edition

The Pixels Dice Hub pairs with up to eight Pixels Bluetooth dice and shows every roll on a pocket-sized touchscreen: one tile per die, a live results panel (sum, highest or lowest), a roll history for each die, and guided rolls for checks, advantage, dice pools and damage.

1. Getting started

Power

  • Turn on / wake: press the BOOT button on the board (the nub on the case edge).
  • Turn off: press and hold the results panel at the bottom of the home screen for 2 seconds, or open Settings and tap POWER OFF. A short countdown overlay lets you cancel by lifting your finger early.
  • Auto sleep: after 15 minutes without any roll or touch the hub powers itself off (adjustable in Settings, see §6).
  • Charging: plug USB-C into the board. The header shows a ⚡ bolt while on USB power and the battery gauge turns green when charging.

Home screen layout

  • Header — NET appears when Wi-Fi is on, then the ⚡/battery gauge of the hub itself, then active / paired dice (e.g. 4/4), and the ⚙ settings cog.
  • Dice tiles — one per active die. The grid re-flows automatically for 1–8 dice.
  • Results panel — the blue bar: tap it to choose SUM / HIGHEST / LOWEST or a guided roll; CLR starts a fresh round.
With nothing paired the home screen reads NO ACTIVE DICE. Tap anywhere on that message to jump straight to pairing.

Orientation

The hub follows its motion sensor: stand it upright for a portrait layout or lay it on its side for landscape. In landscape the results panel moves to the right-hand edge so all tiles stay visible.

Rotation happens a moment after the board settles, so it won't flip while you shake dice.

2. Pairing dice

  1. Tap ⚙ then PAIR DICE (or tap the NO ACTIVE DICE message).
  2. Pick up or roll a die. Every Pixels die the hub can hear appears in the list with its type, name and signal strength. Already-paired dice are outlined green; new ones are outlined blue.
  3. Tap ADD next to a die to pair it. The hub connects briefly to read its details, and the die shows up on the home screen on its next roll.
  4. Tap REMOVE to forget a die. Pairings are saved and survive power-off.
  5. BACK returns to Settings; DONE returns home.
Up to 8 dice can be paired. Dice that have not been heard for 30 minutes drop off the dashboard (the header count shows e.g. 3/4) but stay paired and reappear as soon as they move.

Tips

  • Rolling a die wakes it and makes it advertise — if a die is missing from the list, give it a shake.
  • Signal strength (dBm) closer to 0 is better; −60 dBm is a strong signal, −90 dBm is marginal.
  • Pairing is also available from the web UI (§6) for typing-free setup from a phone.

3. Reading the dashboard

Each paired die gets a tile. The layout adapts to the number of active dice — one big tile, two stacked, a 2×2 grid, and so on up to 2×4 (or 4×2 in landscape).

Anatomy of a tile

  • Type (top-left) — D4, D6, D8, D10, D00, D12, D20, D6P (pipped) or D6F (fudge), colour-coded per type. D? means the die hasn't reported its type yet.
  • Battery (top-right, or bottom-right on narrow tiles) — the die's own battery: grey normal, orange ≤25 %, red low, green charging.
  • Value — the last face rolled. While a die is in motion the previous value is dimmed.
  • State ring (bottom-left) and tile tint — see the table.
Ring colourDie state
GreenRolled — value is final and counted in the results
BlueRolling — in the air or tumbling
AmberHandling — being picked up / held
RedCrooked — landed on an edge; re-roll
VioletOn face — resting, no new roll yet
GreyNo recent data from the die

Tap a tile to open that die's roll history (§5).

4. Results panel — sum, highest, lowest

The blue panel at the bottom combines the latest roll from every die into one number. Its label shows the mode and how many rolls have been counted this round, e.g. SUM > 4R = sum of 4 rolls.

  • SUM — total of all dice rolled this round.
  • HIGHEST — the single best roll this round.
  • LOWEST — the single worst roll this round.

Rounds

A round collects one roll per die. Rolling the same die again replaces its earlier value, so the number always reflects the current state of the table. Tap CLR to clear the panel and start a new round — it shows “–” until the first die lands. Clearing never touches the per-die history.

Changing mode

Tap the panel (short tap — a 2-second hold powers off) to open ROLL MODE. The top group, ROLL RESULTS, switches between SUM, HIGHEST and LOWEST and returns home immediately. The GUIDED ROLLS group below it opens the calculator described in §7. The same page is reachable from ⚙ → ROLL MODE.

The chosen mode is remembered across power cycles.

5. Die history and die info

Roll history

Tap any tile to see that die's recent rolls, newest first, each with how long ago it landed. The list keeps the last 20 rolls per die while the hub is powered.

  • BACK returns to the dashboard.
  • INFO opens the die's detail page.

Die info

Shows the die's unique ID, battery level and charging flag, current state, signal strength and — once the hub has connected to it — firmware details. REFRESHING DETAILS is shown until the connection completes.

UNPAIR DIE removes the die immediately and saves the change. There is no confirmation — re-add it from PAIR DICE if you tap it by mistake.

Web history

When Wi-Fi is on, the web UI (§6) shows a combined timeline of the last rolls from every die, updating live.

Tap ⚙ in the header. Scroll the list by dragging. DONE returns home.

Wi-Fi and the web UI

  1. Tap WIFI OFF → it becomes WIFI AP. The hub creates a hotspot named Pixels-Dice (password pixelsdice).
  2. Join it from a phone or laptop and open http://10.47.1.1. The web UI mirrors the screen, adds a roll timeline and has its own ⚙ settings page.
  3. In the web settings, enter your home network name and password under Join network. The hub connects and the screen row changes to WIFI CONNECTED with the new address underneath.
  4. Tap the row again at any time to turn Wi-Fi off; from AP mode, Forget network in the web UI clears saved credentials.
Wi-Fi shares the radio with Bluetooth. Leave it OFF at the table for the most responsive dice and longest battery life; turn it on when you want the web view or to change settings from a phone.

7. Advanced — guided rolls (calculator)

Guided rolls walk you through a multi-step roll and work out the answer: a D20 check against a difficulty class, advantage/disadvantage, success-counting dice pools, keep-highest/lowest, and damage totals. Open them from the results panel or ⚙ → ROLL MODE, under GUIDED ROLLS.

How a round works

  1. Pick a preset and adjust its options with the −/+ and toggle buttons. Tap the blue preset name to switch to a different preset.
  2. Tap START ROUND. The hub tells you which die to roll and how many rolls remain (e.g. Roll D20 Onyx – 1/2 for the first of two rolls). Rolls from other dice are ignored.
  3. When the last roll lands the result is shown in green (or red for a failed check). ROLL AGAIN repeats the same setup; BACK returns to Settings.
  4. CANCEL during a round abandons it without changing the results panel.
If the required die type isn't paired, the config page shows a red hint such as Need D20 or D4/D6/… and START is refused. DIE: AUTO picks the die type you have the most of (largest wins a tie); tap it to lock the pool to a specific type. If you have fewer dice than ROLLS, simply roll the same die again.

D20 CHECK

One D20 roll plus a modifier (MOD, −20…+20). Turn TARGET on to compare against a difficulty class (DC); the result then reads 17 – SUCCESS DC 10 or 5 – FAIL DC 10. No D20 paired? The hub combines two or three smaller dice (e.g. a D4 and a D6) into a fair 1–20 roll and tells you which to roll.

ADVANTAGE / DISADVANTAGE

Roll the D20 twice; the hub keeps the higher (advantage) or lower (disadvantage) roll and adds MOD. The instruction line counts 1/2, 2/2 so you always know where you are. Use the same die for both rolls, or two D20s — either works.

SUCCESS POOL

Roll ROLLS dice and count how many meet or beat TARGET. Ideal for World-of-Darkness-style pools or Shadowrun hits. Rolls land in any order; each roll of the chosen die type advances the count.

KEEP HIGHEST / KEEP LOWEST

Roll ROLLS dice and sum only the best (or worst) KEEP of them — e.g. 4d6 keep 3 for ability scores. The result shows the kept total.

DAMAGE

Sum ROLLS dice of one type and add MOD. Toggle CRIT on to double the dice total before the modifier is added. DIE: AUTO picks the type you have most of.
